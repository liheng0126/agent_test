④ 人工标注与误差分析 L3 分析归因层

对应职责「组织人工标注、质量抽检、误差分析和问题归因」：人工判断是整个体系的「金标准」，负责校准自动评测器、仲裁争议样本，并把评测失败转化为可执行的改进结论。

🎯 人工介入的三个定位：① 校准者（为 LLM-as-Judge 提供对齐金标）、② 仲裁者（处理自动评测的分歧与低置信样本）、③ 分析师（对失败样本做深度归因）。人工资源贵，必须用在刀刃上。

标注体系设计

📋标注规范（Guideline）

每类任务编写标注手册：维度定义、评分锚点（每个分值的正反例）、边界情况裁决规则。规范版本化管理，每次校准会后的修订全员同步。

🔤标注任务类型

打分式（单答案 1-5 分，评正确性/相关性等）；对比式（A/B 两答案选优或平局，更适合感知细微差异）；分类式（bad case 问题类型归档）；抽取式（标注 evidence 依据片段）。

🎯金标集（Golden Set)

由资深标注员 + 算法同学共建的高置信度基准集（约 500 条/维度），用途：Judge 校准、标注员考核、回归哨兵。

标注流程与质量控制

  1. 任务构造从评测结果库自动抽取待标注样本：Judge 低置信样本、成对评测分歧样本、新增场景抽样、线上负反馈。
  2. 背靠背标注每条样本至少 3 人独立标注，互相不可见；埋入 5% 金标题实时监控标注员质量。
  3. 一致性校验计算标注员间一致性（Cohen/Fleiss Kappa），Kappa ≥ 0.75 视为规范可执行；低于阈值先回炉校准再继续。
  4. 仲裁分歧样本提交仲裁流程：3 人意见不一致时由资深标注员 / 算法同学裁决，裁决结果回写规范附录。
  5. 质量抽检质检员对已提交标注按 10% 比例盲抽复核，错误率 > 5% 的批次整批退回重标。
  6. 结果入库标注结果回流评测结果库：校准 Judge、修正指标分数、沉淀为新金标 / bad case。

误差分析与问题归因方法（Error Analysis）

评测回答「多差」，误差分析回答「为什么差、差在哪、怎么修」。四步分层下钻：

1
失败样本圈定自动评测 + 抽检确认
2
类型归因幻觉/遗忘/漂移/工具失败…
3
分层下钻按场景/难度/版本切片
4
环节定位定位到 prompt/检索/模型/工具
5
改进闭环Owner 认领 → 修复 → 回归
问题类型常见根因对应改进手段
幻觉知识缺失、检索未命中、过度生成补知识库 / 加引用约束 / 拒答策略
上下文遗忘窗口截断、关键信息位置偏远压缩策略 / 信息前置 / 分轮摘要
角色漂移系统提示弱化、长对话稀释人设强化注入 / 周期性提醒
工具调用失败参数 schema 理解错、接口变更工具描述优化 / 参数校验重试
安全风险越狱诱导、注入攻击护栏升级 / 红线集回归

问题闭环管理

  • 归因结论工单化：每个批量问题生成改进工单，明确 Owner、优先级（按 case 量 × 严重度排序）与验收标准（对应回归集指标）。
  • 周度误差分析会：评测、算法、平台、产品四方参加，过 Top 问题、拍板改进方案、回顾上周工单关闭率。
  • 复发现监控：已修复问题进入哨兵状态，回归集中持续监控 2 个版本周期，无复发才归档。
  • 知识沉淀：典型问题与归因结论沉淀为「质量知识库」，供 prompt 工程师和产品同学检索学习。
